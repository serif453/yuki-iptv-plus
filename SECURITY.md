# Security Policy

## Reporting a vulnerability

Please **do not open a public issue** for security problems, such as anything
that could leak credentials, run arbitrary code from a malicious playlist or
EPG file, or write files outside the intended folders.

Report it privately through GitHub:

1. Open the [**Security** tab](https://github.com/serif453/yuki-iptv-plus/security)
   of this repository.
2. Choose **Report a vulnerability**.
3. Describe the problem, the affected version, and steps to reproduce.
   Remove playlist URLs, Xtream credentials and tokens from anything you
   attach.

Only the maintainer can see the report. You will get a reply through GitHub as
soon as the maintainer can review it. This is a small volunteer project, so
please be patient.

## Supported versions

Only the latest release of yuki-iptv plus receives fixes.

## Scope

Issues in the vendored third-party code (`usr/lib/yuki-iptv/thirdparty/`) or in
mpv itself should also be reported to those projects.
